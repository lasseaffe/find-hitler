## [16:15] Study Mode Task 6: Pack CRUD API
- Created three new API route files for study pack management
- `POST /api/study/pack` — create new study pack with name, subject, grade; auto-assigns authorId from session; defaults to draft status
- `GET /api/study/pack/[id]` — fetch full pack with author profile, ordered articles, ratings, session count; includes article difficulty/subject/grade in nested data

- `DELETE /api/study/pack/[id]/articles` — remove single article from pack via articleId
- Uses `auth()` from `@/auth` for session; Prisma composite key syntax `packId_articleId` for junction updates
- Proper error handling + NextResponse wrappers; 201 status for POST, 403 for unauthorized updates
